# 灵感徽章 · Launch 页设计规范

> 动笔之前必须先定的四件事：**叙事结构 / 视觉基调 / 动效语言 / 硬性约束**。
> 任何一方改动都要先改这份文件，再改代码。

---

## 一 · 叙事结构

**一条连续的滚动叙事，顺序 = 用户真实使用 App 的顺序。**

看见一件小物 → 对准它 → 抠出它 → 认出它 → 收进采集台 → 真正拥有它 → 安心（照片不出设备）→ 带走。

| # | 段落 | 讲什么 | 为什么在这个位置 |
|---|---|---|---|
| 01 | 浅色开场 | 一台立体手机居中，随滚动转动；背后是巨大的浅灰品牌字 | 先给"这是一个 App"，浅色 = 纸，与内页同一个世界 |
| 02 | 转暗场 | 同一台手机裂成三台并排，底色转黑，四步进度条点亮 | **全站唯一一次明暗切换**，也是叙事转折：从"一个 App"变成"一条流程" |
| 03 | 小物星云 | 没有标题、没有说明，一颗可拖动旋转的**点阵星云**；形态在真实小物之间缓慢变形 | 参考站这里是"地球"。**我们不抄这个母题** —— 地球讲的是"世界"，我们讲的是"你身边的那些小物"，所以用剪影采样出来的点阵星云（见视觉基调第 4 条） |
| 04 | 加速·黑场·显现 | 继续滚动，星云加速旋转，到全速后短暂停留，整屏黑场，导语屏从黑里显现 | 把上一段"可玩的物件"收束成一句主张 |
| 05 | 导语逐词点亮 | 标题起初全灰，随滚动一个词一个词亮起来 | 让用户"自己读出来"，而不是被塞一句 slogan |
| 06 | 四个功能章节 | 对准 / 抠出 / 认出 / 收藏，每章一套与内容对应的进场效果 | 对应 App 的四步主流程，顺序与界面一致 |
| 07 | 点阵告示屏 | 紧跟"认出"之后，用车站公告牌的形式讲清**识别的适用范围** | 诚实：常见小物认得，文件/钞票这类会给泛化词，名字可以自己改。放在宣称能力的旁边，而不是藏起来 |
| 08 | 隐私手电筒 | 全区文字压暗，圆形跟鼠标/手指走，把圆里的字提亮 | 隐私是产品的地基，用"照亮"这个动作讲，不用徽章图标 |
| 09 | 下载收尾 | 暗场，底部是三万多个像素点组成的点阵；标题可拖动，相邻字按距离衰减跟随，松手弹回 | 最后留给用户一个"可以上手玩"的东西，再给下载入口 |

## 二 · 视觉基调

1. **两个场，一套色**
   - **浅场：只有 01。** 纸 `#FBFAF8`、暖黑 `#1A1712`、次级 `#5C554D`、细线 `#00000014`
   - **暗场：02 起一路到 09 收尾。** 底 `#0E0D0C`、纸白 `#F5F2EE`、次级 `#A8A29B`、细线 `#FFFFFF1A`
     （"唯一一次明暗切换"是硬约束：不做来回反转。08 的手电筒只有在暗场里才成立）
   - **唯一强调色**：琥珀。浅场 `#A65F1B`（对纸 4.71:1），暗场 `#E8A03C`。全站只用于"主行动"与"被点亮的词"。
2. **不用一张图**。所有视觉（手机、点阵、涟漪、像素点）都由代码生成。理由：与"照片不出设备"的产品气质一致，也保证加载体积与离线可用。
3. **字体只用系统字体**（SF Pro / 苹方），与 App 同一套字号逻辑；不引入 webfont。
4. **小物星云的形态数据来自我们自己的剪影**：6 个小物（杯、钥匙、叶、伞、书、耳机）的剪影按像素采样成 ≈7500 个点；变形在两点集之间按最近邻插值。**不使用 Natural Earth 或任何现成地图数据** —— 我们不讲"世界"，讲"你身边的物件"。
5. **禁止清单**：渐变背景、发光、emoji、圆角卡片堆叠、居中一切、装饰性鼠标光斑、自动轮播。

## 三 · 动效语言

**一句话：每个动效都要表达"采集的物理连续性"——被抬起、落进台面、对齐、被拿走。**

- **时间轴只有一个**：滚动位置。不做自动播放、不做定时轮播。用户滚到哪，故事讲到哪。
- **缓动统一**：位移用 `cubic-bezier(.22,1,.36,1)`（弹簧感），时长基准 **650ms**（与 App 的动效基准一致）。
- **允许**：视差、逐词点亮、字符解码、同心涟漪、点阵扩散、拖拽跟随与弹回、明暗切换。
- **禁止**：脉冲、闪烁、无意义自转、`repeatForever` 类装饰动画、鼠标装饰光斑。
- **降级**：`prefers-reduced-motion: reduce` 时，一切位移与粒子动画替换为纯淡入，滚动仍然线性推进叙事。

## 四 · 硬性约束

| # | 约束 | 验收方式 |
|---|---|---|
| 1 | **不加载任何第三方脚本**（three.js 本地 vendor，其余全部手写） | 断网打开仍完整可用 |
| 2 | **不加载任何图片素材**；点阵与几何全部代码生成 | `git ls-files \| grep -E '\.(png\|jpg\|webp)$'` 只允许 logo 与截图 |
| 3 | 首屏 JS ≤ 200KB（不含 three.js 本体时另计） | 构建后统计文件大小 |
| 4 | **无追踪、无统计、无外部请求** | DevTools Network 只有本地文件 |
| 5 | `prefers-reduced-motion` 全部降级 | 用模拟器/系统设置实测 |
| 6 | 移动端可用：滚动手势优先，拖拽在触屏同样生效（touch 事件），无横向溢出 | 375px 宽实测截图 |
| 7 | 无障碍：语义化标签、键盘可达、对比度 ≥ 4.5:1（小字） | 逐项核对 + 无头截图 |
| 8 | 不抄参考站的视觉母题（尤其"地球"） | 第 03 段必须是我们的"小物星云" |
| 9 | 每一段都要能单独截图验证（`?p=0.35` 之类的时间轴参数） | 无头 Chrome 截图 |
